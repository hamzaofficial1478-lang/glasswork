# run.py already tried to install from this file after an update — and the file

# HTTP with sane defaults. Used by the provider client, the channel tests and
# the site connector. Everything else fetches with urllib.
requests>=2.31

# GOOGLE SEARCH CONSOLE — optional, and the best free thing on the list.
#
# Only pipelines/seo_intel.py imports these, only when GSC_PROPERTY is set, and
# it degrades with a plain message telling you to run this install rather than
# raising. Service-account auth signs a JWT with RS256, which needs a real
# crypto library — there is no stdlib way round it.
#
# Without these: SEO still works. It ranks keywords on autocomplete breadth,
# your own enquiries and rival pages. What you lose is the one source that
# knows which searches ALREADY reach your site, and the striking-distance list
# that comes with it.
google-auth>=2.29

# The always-on crew in runner/service.py. Not needed for run.py, the office,
# the setup screen, or any pipeline — install it only if you run that.
# claude-agent-sdk

# PRIVATE ACCOUNTS — each person's data encrypted on this computer.
#
# cryptography locks each account's master key with the password and the
# recovery key, and seals the settings files. sqlcipher3-wheels is SQLite with
# encryption built in, for each website's cabinet (coordination/cipher.py);
# it ships ready-built for Windows, Mac and Linux.
#
# Without these: the program runs exactly as before. Making an account is what
# needs them, and the account screen says so.
cryptography>=41
sqlcipher3-wheels>=0.5

# PHONE NUMBERS IN ANY COUNTRY — Google's numbering rules, so "0161 496 0000"
# in Manchester and "04 385 1122" in Dubai are each read in their own country's
# format (coordination/countries.py). Without it a short built-in table keeps
# the common countries working.
phonenumbers>=8.13
