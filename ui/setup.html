2 · The Claude teamWhich Claude model each sector thinks with. Each row saves on its own.

Every sector thinks with Claude, using the login Claude Code already has on this machine — no API keys. Nothing above Opus 5 can be picked. If a model is slow or busy, that sector steps down to the next model (Opus 5 → Opus 4.8 → 4.7 → 4.6 → Sonnet → Haiku) and every other sector steps round it too, for a few minutes. MD, Security and IT are the main three: when the main account's allowance runs out they move to the backup account at their full model, and the others give way.

8 · Preflight — test everything at onceThe Claude team, every shelf API, every channel — and whether your fallbacks actually work

Checks each Claude account is signed in, asks each model on the team to say OK, and tests every API on every shelf — so you find out now, not at 2am, whether losing a primary actually costs you anything. Each result is one of: COVERED (two or more links work, you're safe), SINGLE (only one works — a single point of failure, even if you thought you had a fallback), or DOWN (nothing works).

The full check makes a real, tiny call to every model, so it costs a few tokens. The quick check skips those and only reports what it can verify without calling.
